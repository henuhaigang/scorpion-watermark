**macOS 桌面图片水印工具。** 为图片添加斜向平铺可见文字水印，导出时自动剥离 EXIF/GPS 等隐私元数据。**完全本地离线处理，不发起任何网络请求。**

首个发布版本。

## 系统要求

- macOS 11.0 或更高
- 架构：**Apple Silicon (arm64)**，即 M1 及之后的 Mac

> **Intel Mac 用户暂无法使用本版本。** 官方打包流程可产出 Universal Binary，
> 但需要 `rustup target add x86_64-apple-darwin` 可用；请参考项目 README
> 「打包 DMG」章节自行构建，或等待后续提供 Universal 版本。

## 安装

1. 下载 DMG
2. 打开 DMG，把 `Scorpion Watermark.app` 拖进「应用程序」文件夹
3. 首次启动需要绕过 Gatekeeper（见下）

### ⚠️ 首次打开会被 Gatekeeper 拦截

本版本使用 **ad-hoc 签名**（未购买 Apple 开发者证书），macOS 会提示「无法验证开发者」。**任选一种方式绕过：**

- **右键点击** `Scorpion Watermark.app` → 选择「打开」→ 在弹窗中确认「打开」
- 或在终端执行：

```bash
xattr -cr /Applications/Scorpion\ Watermark.app
```

> 后续版本若完成 Apple 公证即可去掉此步骤。

## 使用

1. 拖入图片，或点击选择文件（支持 JPG / PNG / WebP / GIF / HEIC）
2. 在右侧填写水印文字，调整角度、透明度、字号比例、行间距、颜色
3. 画布实时预览效果
4. 选择输出格式，点击「导出」并指定保存位置

导出会**另存为新文件，永不覆盖原图**，并默认剥离 EXIF/GPS/IPTC/XMP 等元数据。

顶部预设栏可保存参数组合并一键复用。

## 已知问题

**PDF 导出会破坏原文件内容。** 底层实现会覆盖页面的内容流，导出的 PDF 会丢失原始页面内容，且字体资源、透明度、铺排均未实现。**请勿对本工具的 PDF 导出功能使用。**

**隐形水印与鉴定功能不可用。** 底层库 `blind_watermark` 0.1.3 的提取功能失效：嵌入确实会修改像素，但提取恒返回全 0，改变种子模式、嵌入强度、图像尺寸、载荷长度均无效。0.1.3 已是最新版，无修复版本。

该功能已整体停用，UI 入口已移除，接口返回明确错误。鉴证功能给出错误结论的危害大于功能缺失，因此不做静默降级。恢复需要先解决底层问题：vendor 该库定位修复，或自行实现一套嵌入/提取方案。

**RAW 格式不支持。** 文件选择器中列出了 `raw`，但加载会失败。

**子集字体可能缺字。** 内置字体为 GB2312 子集，生僻字不在其中时会显示为方块或回退字体，预览区会给出红色提示。

## 设计说明

**长文本排版策略**：文字永远不会截断，也永远不会加省略号。系统会按以下顺序选择方案 ——

1. 若在设定字号下能单行放下，就用单行（哪怕设定字号偏小也尊重你的选择）
2. 否则逐行增加，取行数最少、且字号不低于画布宽度 2% 的方案（宁可换行也要保证看得见）
3. 兜底：维持设定字号，取能放下全文的最少行数

字号绝对下限为画布宽度的 1.5%，最多 3 行。

**预览与导出一致**：前后端使用同一个字体文件，有测试校验两份文件字节完全相同；预览会等待字体加载完成后才排版，避免用回退字体绘制。
